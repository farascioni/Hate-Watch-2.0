## Index

**Summary:** the app's own words (every screen) come from `app/src/lib/strings/<language>.ts` through `useT()` / `tr()` in `app/src/lib/i18n.ts`. English is the source and the fallback. ## How it works
- `strings/en.ts` holds every key (`'tab.feed'`, `'settings.push'`, ...) as `as const`; `Key` is its type. Every other file (`es`, `fr`, `pt`, `de`, `ja`) is `Record<Key, string>`, so `npx tsc --noEmit` fails on a missing key. At run time a missing key falls back to English (`DICTS` is a `Partial`).
- The device language is `Intl.DateTimeFormat().resolvedOptions().locale`, first two letters; one we don't have is English. `expo-localization` is not installed on purpose: a native module changes the OTA fingerprint and updates would stop reaching builds already out.
- Settings → Language (Device, then every language in its own name) calls `setLangPref()`. The choice is kept in AsyncStorage under `hw.language`; Device removes it. It is a module store like `lib/trackingLayout.ts` (listeners and `useSyncExternalStore`), so the screens re-render at once.
- `useT()` in components, `tr()` outside React (`Alert.alert`, share text). `{name}` placeholders are filled from the variables; when `n` is 1 and `<key>_one` exists, it is used instead (English, Spanish, French and Portuguese use `_one` for 1; German too; Japanese has no plural, so its `_one` keys only drop the count where the English keeps it). Numbers passed as variables are formatted with the language's Intl tag. `phrase()` and `wordT()` map a server word (`games`, `races`, `fighters`) to `word.*` / `<base>.<word>` keys, so the sentence stays grammatical in every language.
- On the web, `_layout.tsx` sets `document.documentElement.lang` to the current language (screen readers, the browser's translate prompt) and keeps it in step when the picker changes.
- `currentLocale()` is the picked language's Intl tag (`en-US`, `es-419`, `fr-CA`, `pt-BR`, `de-DE`, `ja-JP`), or `undefined` for Device, which keeps the device's own formatting. Dates, times and numbers on the screens use it.

## What is translated, and what is not
- Done: every screen and component, in the six languages: tabs, Settings, the startup guide, Scores, Tracking, Search, the Feed, the player/team, alert, game, F1, UFC, stats and leaderboard screens, Hate Watch Plus and its store (the subscription fine print follows Apple's and Google's wording in each language), Favorites and the counter, the share sheet, feedback and update prompts, and the web shell.
- Not translated: `lib/push.ts` (the push channel's name), the dev-only rows in Settings, and the lock screen scoreboard and home screen widgets (native code; the board's lines are composed by the server in `server/src/live-activity.ts` and drawn by `app/src/widgets/ScoreboardActivity.tsx`, so translating them means sending the device language to the server and a server deploy).
- Never from the app: alert titles and bodies, push text, league names, chips and event names, and an alert's group names and labels are the server's (`ui` in `server/src/leagues.ts`, `server/src/event-types.ts`) and stay English until the server writes them in the reader's language.

## Adding a language
1. `strings/<id>.ts` (add every `en.ts` key; `npx tsc --noEmit` lists what is missing), typed `Record<Key, string>`, in the wording of `app-store/listings/<id>.md`.
2. `i18n.ts`: add it to `Lang`, `DICTS`, `LANGS` and `TAGS`.
3. This file and `PATCH_NOTES.md`.

## Review
- Spanish: "Clasificación" for the leaderboard, and the football words "down" and "outs" left in English as US Spanish fans say them. Informal "tú" throughout.
- Special Events segment names (`scores.special.*`): French "Séries" (playoffs) and "Bowls", Spanish/Portuguese/German "Playoffs" and "Bowls", Japanese "プレーオフ" and "ボウル" are unreviewed by a native speaker. The alert toggle lines under the vote (`event.alertMe`, `event.alertTracked`) in French, Portuguese, German and Japanese are unreviewed too.
- French: the Scores tab's "Toute l’action" (all events) was shortened from "Tous les événements" so it fits the three-segment switch; it does not pair with "Mes événements", so a reviewer may want a better pair. "vous", Canadian baseball terms ("buts", "au bâton"), "fil" for feed, "pointages" for scores, "détracteurs" for haters.
- Portuguese (Brazil): "Acompanhar/Acompanhando" for track, "placar", "feed" and "haters" kept.
- German: informal "du", "Alerts" and "Feed" kept as German fans say them, "Folgen/Verfolgt" for track, "Nicht mehr folgen" for unfollow, "Hater". Sentences that take a case ("Du folgst keinen {what}") are written for each word in `word.*`.
- Japanese: 追跡/追跡中, アラート, フィード, スコア. Baseball and football words are the usual katakana or kanji ones (打者, 一塁); F1 and the UFC use the English-derived names fans use.
- All five were written by Claude. None has had a native-speaker review yet; do that before an update ships them (settings → Language is the quickest way to read them).
