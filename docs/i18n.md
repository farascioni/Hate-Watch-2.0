## How it works
- `strings/en.ts` holds every key (`'tab.feed'`, `'settings.push'`, ...) as `as const`; `Key` is its type. `strings/es.ts` is `Record<Key, string>`, so `npx tsc --noEmit` fails on a missing key. At run time a missing key falls back to English (`DICTS` is a `Partial`).
- The device language is `Intl.DateTimeFormat().resolvedOptions().locale`, first two letters; one we don't have is English. `expo-localization` is not installed on purpose: a native module changes the OTA fingerprint and updates would stop reaching builds already out.
- Settings → Language (Device / English / Español, each in its own language) calls `setLangPref()`. The choice is kept in AsyncStorage under `hw.language`; Device removes it. It is a module store like `lib/trackingLayout.ts` (listeners and `useSyncExternalStore`), so the screens re-render at once.
- `useT()` in components, `tr()` outside React (`Alert.alert`, share text). `{name}` placeholders are filled from the variables; when `n` is 1 and `<key>_one` exists, it is used instead (no plural key exists yet).
- `currentLocale()` is the picked language's Intl tag (`en-US`, `es-419`), or `undefined` for Device, which keeps the device's own formatting. The quiet hours in Settings use it; the other date and number formatting still uses the device's.

## What is translated, and what is not
- Done: the tab names and the Tracking count, the leaderboard button's label, and all of Settings (delivery, scoreboard layout names and blurbs, quiet hours, the alert groups' text, data, About, the Language picker and every alert box).
- Not yet: the startup guide, Scores, Tracking, Search, the player, team, game, F1, UFC, stats and leaderboard screens, Hate Watch Plus and its store, the Favorites and counter cards in Settings, the lock screen scoreboard's text, and the plurals. The dev-only rows in Settings stay English.
- Never from the app: alert titles and bodies, push text, league names, chips and event names, and an alert's group names and labels are the server's (`ui` in `server/src/leagues.ts`, `server/src/event-types.ts`) and stay English until the server writes them in the reader's language.

## Adding a language
1. `strings/<id>.ts`, typed `Record<Key, string>`, in the wording of `app-store/listings/<id>.md`.
2. `i18n.ts`: add it to `Lang`, `DICTS`, `LANGS` and `TAGS`.
3. This file and `PATCH_NOTES.md`.
